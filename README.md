# 4-bit ALU Verilog - VLSI Mini Project
Best for VLSI | Tools: Verilog, Vivado

A 4-bit Arithmetic Logic Unit that performs 8 operations.

## Operations
000-ADD, 001-SUB, 010-AND, 011-OR, 100-XOR, 101-NOT, 110-SHL, 111-SHR

## Tested with a=5, b=3
Simulation waveforms included.
